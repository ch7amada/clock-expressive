# Review F02 (round 1)
Verdict: CHANGES_REQUESTED
## Findings
1. [BLOCKER] app/src/main/kotlin/org/fossify/clock/ui/components/Shapes.kt:270-283 — the running spin is a hot `while (true)` loop in a `LaunchedEffect` on the main dispatcher: it writes `spin`/`settleTarget` (snapshot state) every microsecond with no suspend/await between `withFrameNanos` reads, starves the main Looper, so while running the UI freezes (no frames, no input — the user cannot even tap to pause; ANR; the running preview button freezes too). Required change: replace with a frame-driven, suspendable spin using the documented pattern (docs/rewrite/api/Animation.md and `RotatingShape` at lines 199-210): `rememberInfiniteTransition` + `infiniteRepeatable(tween(12_000, LinearEasing), RepeatMode.Restart)`, displayed only while `isRunning`; on pause either drop the 40° settle (explicitly allowed by the spec: "if it gets complicated, drop the settle and just stop") and freeze at the last angle, or keep the settle by capturing the last angle on pause and animating to `(angle / 40f).roundToInt() * 40f` via `animateFloatAsState(defaultSpatialSpec<Float>())`. Remove the `withFrameNanos` loop and the mutable `spin`/`settleTarget` state.
2. [MAJOR] app/src/main/kotlin/org/fossify/clock/ui/components/Shapes.kt:287-303 — `.pressSquish(interactionSource)` is the innermost modifier in the Box chain (after `.clickable`), so its `graphicsLayer` scale applies only to the icon content; the morphed background shape (the button's visual body) does not squish on press, contrary to the expressive "interactive elements squish on press" intent. Required change: move `.pressSquish(interactionSource)` above `.background(containerColor, shape)` (directly after `.graphicsLayer { rotationZ = buttonRotation }`) so the scale wraps both background and icon.
3. [MINOR] app/src/main/kotlin/org/fossify/clock/ui/components/Shapes.kt:241-243 — comment asserts `MaterialShapes.Square` "already carries some corner rounding" and uses it as the running shape, but the in-repo API reference (docs/rewrite/api/MaterialShapes.md) does not confirm any rounding for `Square`, and the spec requires the square to "look like a rounded square". Required change: verify in the preview; if `Square` renders with hard 90° corners, switch `endShape` to `RoundedPolygon.rectangle(rounding = CornerRounding(0.3f)).normalized()` per the spec.

## PM addendum (authoritative — follow this where it differs from the findings above)
- Finding 1: `withFrameNanos` does suspend once per frame, so this is not a hot loop/ANR — but the code still recomposes the whole
  button every frame (reads `spin` in composition), and `settleTarget` jumps −360° each time the 12 s period wraps. Severity MAJOR.
  **Required implementation** (replaces `spin`, `settleTarget`, `settledRotation`, the `withFrameNanos` loop and `buttonRotation`):
  ```kotlin
  val rotation = remember { Animatable(0f) }                       // androidx.compose.animation.core.Animatable
  val settleSpec = MaterialTheme.motionScheme.defaultSpatialSpec<Float>()
  LaunchedEffect(isRunning) {
      if (isRunning) {
          while (true) {
              rotation.animateTo(rotation.value + 360f, tween(durationMillis = 12_000, easing = LinearEasing))
              rotation.snapTo(rotation.value % 360f)
          }
      } else {
          rotation.animateTo((rotation.value / 40f).roundToInt() * 40f, settleSpec)
      }
  }
  ```
  Read `rotation.value` **only inside a `graphicsLayer { }` lambda** (never in composition).
- Finding 2: agreed (MAJOR).
- Finding 3: **no change** — `MaterialShapes.Square` is defined in material3 as a rectangle with `CornerRounding(0.3f)`, i.e. already rounded. Keep it.
- 4. [MAJOR] Shapes.kt:286-321 — the rotation `graphicsLayer` is on the outer Box, so the Play/Pause **icon spins too**. Only the
  morphing background may rotate. Required structure:
  ```kotlin
  Box(
      modifier = modifier.size(size).pressSquish(interactionSource)
          .semantics { role = Role.Button }
          .clickable(interactionSource = interactionSource, indication = null, enabled = enabled) { haptic; onClick() },
      contentAlignment = Alignment.Center,
  ) {
      Box(Modifier.matchParentSize().graphicsLayer { rotationZ = rotation.value }.background(containerColor, shape))
      AnimatedContent(...) { Icon(...) }   // unchanged, upright
  }
  ```
  This also resolves finding 2 (the squish now wraps background + icon).
