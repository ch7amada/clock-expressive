# Review F03 (round 1)
Verdict: CHANGES_REQUESTED
## Findings
1. [MAJOR] app/src/main/kotlin/org/fossify/clock/ui/components/Dialogs.kt:53,111 — both `ConfirmDialog` and `RadioListDialog` use the `AlertDialog(onDismissRequest) { content }` overload, which per `docs/rewrite/api/AlertDialog.md` "draws no container (no surface, no shape, no padding)" — the dialog renders as bare text in the window with no tonal surface. The spec requires `RadioListDialog` to "use the `extraLarge` shape", and the KDoc at Dialogs.kt:93 falsely asserts "the dialog container uses the default dialog shape (`extraLarge`)". Required change: use the container-drawing overload with `title`/`icon`/`text`/`confirmButton`/`dismissButton` slots (`shape` defaults to `AlertDialogDefaults.shape` = extraLarge per the API doc), or wrap the column in `Surface(shape = AlertDialogDefaults.shape, color = AlertDialogDefaults.containerColor, tonalElevation = AlertDialogDefaults.TonalElevation)`; fix KDoc line 93 to match the actual behavior.
2. [MAJOR] app/src/main/kotlin/org/fossify/clock/ui/components/Lists.kt:62-73 — `segmentedGroup` never applies the vertical spacing `ListItemDefaults.SegmentedGap` between items, which the spec explicitly requires ("and the vertical spacing `ListItemDefaults.SegmentedGap` between items, so callers can build expressive grouped lists"); `SegmentedGap` is not imported or used anywhere in the file, so groups render flat with no visual separation. Required change: emit the gap between items, e.g. wrap each item in `Column(Modifier = if (index > 0) Modifier.padding(top = ListItemDefaults.SegmentedGap) else Modifier) { itemContent(index, shapes) }`.

## PM addendum (authoritative)
- Finding 1: use the standard overload now documented at the end of `docs/rewrite/api/AlertDialog.md`:
  `AlertDialog(onDismissRequest, confirmButton = { TextButton(onConfirm) { Text(confirmLabel) } }, dismissButton = {...},
  icon = icon?.let { { Icon(it, null) } }, title = { Text(title) }, text = { Text(text) })`. For `RadioListDialog`, put the rows in
  `text = { Column(Modifier.selectableGroup()) { ... } }` and give it a `confirmButton` that is a `TextButton(onDismiss)` with
  `org.fossify.commons.R.string.cancel` (selecting a row still calls `onSelect` then `onDismiss`).
- 3. [BLOCKER] Lists.kt `segmentedGroup`: the default key `?: index` makes two groups in the same `LazyColumn` (e.g. Settings) reuse keys
  0..n and **crash** ("Key was already used"). Required: `item(key = key?.invoke(index)) { ... }` (null key = positional).
- 4. [MINOR] Dialogs.kt RadioListDialog rows: `RadioButton(selected = ..., onClick = null)` (the row owns the click/semantics), and each
  row `heightIn(min = 56.dp)` instead of `padding(vertical = 4.dp)` (48dp touch target), `selectableGroup()` on the column.
- 5. [MINOR] EmptyState.kt: `textAlign = TextAlign.Center` on title and body; `Spacer(Modifier.height(24.dp))` before `action()`.
