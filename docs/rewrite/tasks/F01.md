# F01 — Expressive theme (`ui/theme`)

## Goal
Create the app-wide Compose theme `ClockTheme` on top of `MaterialExpressiveTheme`, with Material You dynamic
color, an expressive fallback palette, a user-selectable light/dark/system mode, an optional pure-black dark mode,
Google Sans Flex typography, and expressive shapes and motion. Add the three new preferences to `Config`.
No screen uses it yet; F04 will.

- `app/src/main/kotlin/org/fossify/clock/helpers/Config.kt` lines 1–40 (pattern for prefs)
- `app/src/main/kotlin/org/fossify/clock/helpers/Constants.kt` lines 1–50 (pref key constants live here)

### 2. `helpers/Config.kt` — add three properties (same style as the existing ones)
`var themeMode: Int` (default `THEME_MODE_SYSTEM`), `var useDynamicColor: Boolean` (default `true`),
`var usePureBlack: Boolean` (default `false`).
`prefs` is `protected` in `BaseConfig`, so also add
`fun registerPrefsListener(l: SharedPreferences.OnSharedPreferenceChangeListener)` and
`fun unregisterPrefsListener(l: SharedPreferences.OnSharedPreferenceChangeListener)`.

### 3. `ui/theme/Color.kt`
- A fallback **light** scheme: start from `expressiveLightColorScheme()` (a material3 function), then `.copy(...)`
  primary, secondary, and tertiary families with a warm, playful palette built around seed `#6750A4` (violet primary),
  `#7D5260` (rose tertiary), and `#625B71` (secondary). Provide the explicit `Color(0xFF……)` values for primary,
  onPrimary, primaryContainer, onPrimaryContainer, the same four for secondary and for tertiary, plus surface,
  surfaceContainerLowest…Highest.
- A matching fallback **dark** scheme built with `darkColorScheme(...)`, using proper M3 tonal values (primary ≈ tone 80,
  container ≈ tone 30, surfaces ≈ tone 6–24).
- `fun ColorScheme.toPureBlack(): ColorScheme` — returns a copy with `background`, `surface`,
  `surfaceContainerLowest`, and `surfaceContainerLow` = `Color.Black`, `surfaceContainer` = `Color(0xFF0B0B0B)`,
  `surfaceContainerHigh` = `Color(0xFF141414)`, `surfaceContainerHighest` = `Color(0xFF1E1E1E)`.

### 4. `ui/theme/Type.kt`
- `val GoogleSansFlex: FontFamily` — variable font `R.font.google_sans_flex` (axes: `wght` 1–1000, `wdth` 25–151,
  `opsz` 6–144, `ROND` 0–100, `slnt` −10–0). Declare one `Font(...)` per weight you use (400, 500, 600, 700, 800),
  each with `variationSettings = FontVariation.Settings(FontVariation.weight(w), FontVariation.Setting("ROND", 100f))`
  so the UI gets the soft, rounded look.
- `val ClockTypography = Typography(fontFamily = GoogleSansFlex)`. This 1.5 constructor applies the family to all
  30 styles, including the `*Emphasized` ones. Then `.copy(...)` the emphasized styles to use `FontWeight.Bold`
  (display/headline) or `FontWeight.SemiBold` (title/label).
- `object ClockTextStyles` with hero styles for big time displays. Each is a `TextStyle` using its own
  `FontFamily(Font(R.font.google_sans_flex, variationSettings = …))`:
  - `heroClock`: 96.sp, wght 400, wdth 100, ROND 100, `fontFeatureSettings = "tnum"` (tabular digits), lineHeight 96.sp
  - `heroClockCompact`: 72.sp, same axes but wdth 85
  - `timer`: 64.sp, wght 300, ROND 100, tnum
  - `listTime`: 48.sp, wght 500, ROND 100, tnum (alarm cards)
  - `fun heroWith(weight: Int, width: Float = 100f, sizeSp: Int = 96): TextStyle` — builds a hero style with arbitrary
    axes (used later to animate weight).

### 5. `ui/theme/Shape.kt`
`val ClockShapes = Shapes(extraSmall = RoundedCornerShape(8.dp), small = RoundedCornerShape(12.dp),
medium = RoundedCornerShape(20.dp), large = RoundedCornerShape(28.dp), extraLarge = RoundedCornerShape(36.dp))`.
Check `docs/rewrite/api/Shapes.md`; if `Shapes` in 1.5 has extra parameters such as `largeIncreased` or
`extraLargeIncreased`, set them to 32.dp and 44.dp.

### 6. `ui/theme/Theme.kt`
```kotlin
data class ThemeSettings(val mode: Int, val dynamicColor: Boolean, val pureBlack: Boolean)

@Composable fun rememberThemeSettings(): ThemeSettings
```
reads `LocalContext.current.config` and **stays live**: register a
`SharedPreferences.OnSharedPreferenceChangeListener` via `config.registerPrefsListener` in a `DisposableEffect` and update a
`mutableStateOf`. Keep a strong reference to the listener, because SharedPreferences holds listeners weakly.

```kotlin
@Composable
fun ClockTheme(
    settings: ThemeSettings = rememberThemeSettings(),
    content: @Composable () -> Unit,
)
```
- dark = system mode → `isSystemInDarkTheme()`, light → false, dark → true.
- On API 31+ with `settings.dynamicColor` → `dynamicDarkColorScheme(context)` / `dynamicLightColorScheme(context)`,
  otherwise use the fallback schemes from Color.kt. Apply `toPureBlack()` when dark && pureBlack.
- Animate color changes: wrap each scheme color with `animateColorAsState` only if it stays simple; otherwise skip it.
- Call `MaterialExpressiveTheme(colorScheme = …, motionScheme = MotionScheme.expressive(), shapes = ClockShapes,
  typography = ClockTypography, content = content)`.
- Also export `@Composable fun isAppInDarkTheme(): Boolean`, which applies the same rule (later used for system-bar icons).

### 7. `ui/theme/ThemePreview.kt`
A `@Preview` composable `ThemeShowcasePreview` that renders inside `ClockTheme` a column with: the hero clock text

`MaterialShapes.Cookie9Sided.toShape()` filled with `primaryContainer`. It is used for review and as an API smoke test.
