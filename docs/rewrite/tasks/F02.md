# F02 — Expressive shape kit (`ui/components/Shapes.kt`)

## Goal
Reusable building blocks for Material 3 Expressive **shape morphing**. Later features (stopwatch and timer play/pause,
empty states, clock face, ringing screen) all depend on these, so they must be correct, small, and documented with KDoc.

## Read first
- `AGENTS.md` (in context)
- `docs/rewrite/api/MaterialShapes.md` (`Morph.toPath`, `RoundedPolygon.toShape`)
- `app/src/main/kotlin/org/fossify/clock/ui/theme/Theme.kt` (only to see `ClockTheme` for previews)
- Facts you need (verified):
  - `androidx.graphics.shapes.RoundedPolygon` and `androidx.graphics.shapes.Morph(start: RoundedPolygon, end: RoundedPolygon)`.
  - `MaterialShapes.*` polygons are **normalized to the 0..1 unit square**, so to draw them at size W×H, scale the path
    by (W, H) with `androidx.compose.ui.graphics.Matrix().apply { scale(w, h) }` and `path.transform(matrix)`.
  - material3 extension: `fun Morph.toPath(progress: Float, path: Path = Path(), startAngle: Int = 0): Path`
    (`import androidx.compose.material3.toPath`).
  - material3 extension: `@Composable fun RoundedPolygon.toShape(startAngle: Int = 0): Shape`
    (`import androidx.compose.material3.toShape`).

## Create `app/src/main/kotlin/org/fossify/clock/ui/components/Shapes.kt` with

1. `class MorphPolygonShape(private val morph: Morph, private val progress: Float, private val startAngle: Int = 0) : Shape`
   — `createOutline` builds `morph.toPath(progress, Path(), startAngle)`, scales it to `size`, and returns `Outline.Generic`.
   Override `equals`/`hashCode` on (morph identity, progress, startAngle).

2. `@Composable fun rememberMorph(start: RoundedPolygon, end: RoundedPolygon): Morph` — `remember(start, end) { Morph(start, end) }`.

3. `@Composable fun animatedMorphShape(start: RoundedPolygon, end: RoundedPolygon, atEnd: Boolean,
   animationSpec: FiniteAnimationSpec<Float> = MaterialTheme.motionScheme.defaultSpatialSpec()): Shape`
   — animates progress 0f↔1f with `animateFloatAsState` and returns a remembered `MorphPolygonShape`.

4. `fun Modifier.pressSquish(interactionSource: InteractionSource, pressedScale: Float = 0.9f): Modifier` — a
   `composed {}` modifier (or `Modifier.Node` if you are confident) that collects `collectIsPressedAsState()` and
   animates `graphicsLayer { scaleX = s; scaleY = s }` with `MaterialTheme.motionScheme.fastSpatialSpec()`.

5. `@Composable fun ShapeBadge(polygon: RoundedPolygon, modifier: Modifier = Modifier, size: Dp = 56.dp,
   containerColor: Color = MaterialTheme.colorScheme.primaryContainer,
   contentColor: Color = MaterialTheme.colorScheme.onPrimaryContainer, rotation: Float = 0f,
   content: @Composable BoxScope.() -> Unit = {})` — a `Box` of `size`, background clipped to `polygon.toShape()`,
   with rotation applied **only to the background layer** (use `Modifier.drawBehind` or a separate background `Box`
   with `graphicsLayer { rotationZ = rotation }`), content centered and **not** rotated, and `LocalContentColor`
   provided as `contentColor`.

6. `@Composable fun RotatingShape(polygon: RoundedPolygon, modifier: Modifier = Modifier,
   color: Color = MaterialTheme.colorScheme.primaryContainer, periodMillis: Int = 24_000)` — a decorative shape that
   rotates endlessly with `rememberInfiniteTransition` (linear easing is fine here). It fills the modifier's size.

7. `@Composable fun MorphingPlayPauseButton(isRunning: Boolean, onClick: () -> Unit, modifier: Modifier = Modifier,
   size: Dp = 96.dp, enabled: Boolean = true)` — the signature expressive control for the stopwatch and timers:
   - shape: `animatedMorphShape(MaterialShapes.Cookie9Sided, MaterialShapes.Square, atEnd = isRunning)`.
     The square must look like a rounded square: if `MaterialShapes.Square` is too sharp, use
     `RoundedPolygon.rectangle(... rounding = CornerRounding(0.3f)).normalized()` instead.
   - container color animates `primary` (stopped) → `tertiaryContainer` (running) with `animateColorAsState`, using
     `MaterialTheme.motionScheme.defaultEffectsSpec()`; content color `onPrimary` → `onTertiaryContainer`.
   - icon: `Icons.Rounded.PlayArrow` ↔ `Icons.Rounded.Pause` with `AnimatedContent` (scale and fade), icon size `size * 0.42f`.
   - `Modifier.pressSquish(...)`, `semantics { role = Role.Button }`, haptic `HapticFeedbackType.ToggleOn/ToggleOff`
     on click, and contentDescription from `R.string.start` / `R.string.pause` if they exist (grep
     `app/src/main/res/values/strings.xml` and Fossify `org.fossify.commons.R.string`). Otherwise add `m3e_start` /
     `m3e_pause` to `app/src/main/res/values/strings.xml`.
   - Whole button rotates gently while running: `rotationZ` animates continuously (one turn per 12 s) only when
     `isRunning`, and it settles back to the nearest multiple of 40° (9-sided symmetry) when paused. Keep this simple; if it gets
     complicated, drop the settle and just stop.

8. `@Preview` composables inside `ClockTheme`: `ShapeBadgePreview` (three badges: Sunny, Cookie12Sided, Flower) and
   `MorphingPlayPausePreview` (two buttons, running and stopped).
