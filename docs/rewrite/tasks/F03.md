## Create

### `ui/components/EmptyState.kt`
`@Composable fun ExpressiveEmptyState(icon: ImageVector, title: String, modifier: Modifier = Modifier,
body: String? = null, polygon: RoundedPolygon = MaterialShapes.Cookie12Sided, action: (@Composable () -> Unit)? = null)`
— centered column: a 168.dp slowly rotating shape (`RotatingShape`, color `secondaryContainer`) with the icon
(64.dp, `onSecondaryContainer`) centered on top of it (use a `Box`), then the title in `headlineSmallEmphasized`, body in
`bodyLarge` / `onSurfaceVariant`, and the optional action below. It enters with a spring scale-in
(`AnimatedVisibility` / `animateFloatAsState` from 0.8f, `motionScheme.defaultSpatialSpec()`).

### `ui/components/AnimatedTimeText.kt`
`@Composable fun AnimatedTimeText(text: String, style: TextStyle, modifier: Modifier = Modifier,
color: Color = Color.Unspecified)` — renders a time string such as `"07:42:09"` **character by character** in a `Row`.
Every character slot is an `AnimatedContent(targetState = char)` whose transition, when a **digit** changes, slides the
old digit up and out and the new one up and in (`slideInVertically { it } + fadeIn togetherWith slideOutVertically { -it } + fadeOut`),
using `MaterialTheme.motionScheme.fastSpatialSpec()` for offsets and `fastEffectsSpec()` for fades. Non-digit
characters (`:`, `.`, spaces, AM/PM) do not animate. Use `key` per index so only changed slots animate. Clip each slot so
sliding digits do not overlap neighbours. Add a `semantics { contentDescription = text }` on the row and
`clearAndSetSemantics` so TalkBack reads the whole string once.

### `ui/components/Dialogs.kt`
1. `@Composable fun ConfirmDialog(title: String, text: String, confirmLabel: String, onConfirm: () -> Unit,
   onDismiss: () -> Unit, icon: ImageVector? = null, dismissLabel: String = stringResource(org.fossify.commons.R.string.cancel))`
   — `AlertDialog`; confirm is a `TextButton`.
2. `@Composable fun <T> RadioListDialog(title: String, options: List<Pair<T, String>>, selected: T,
   onSelect: (T) -> Unit, onDismiss: () -> Unit)` — `AlertDialog` whose text is a column of rows, each row
   `Modifier.selectable(role = Role.RadioButton)` with a `RadioButton` + label. Selecting calls `onSelect` and then `onDismiss`.
   Uses the `extraLarge` shape.

### `ui/components/Lists.kt`
1. `@Composable fun SectionHeader(text: String, modifier: Modifier = Modifier)` — `labelLarge` (or
   `titleSmallEmphasized`) in `primary`, padding start 16.dp, top 24.dp, bottom 8.dp.
2. `fun LazyListScope.segmentedGroup(count: Int, key: ((Int) -> Any)? = null,
   itemContent: @Composable (index: Int, shapes: ListItemShapes) -> Unit)` — emits `count` items. Each item gets
   `ListItemDefaults.segmentedShapes(index = i, count = count)` and the vertical spacing `ListItemDefaults.SegmentedGap`
   between items, so callers can build expressive grouped lists (first and last items rounded more strongly).
   `segmentedShapes` is `@Composable`, so call it inside the item lambda.
3. `@Composable fun SegmentedPreview()` preview: a `LazyColumn` with a `SectionHeader` and a 3-item `segmentedGroup` of
   `SegmentedListItem(onClick = {}, shapes = shapes, leadingContent = { Icon(...) }, supportingContent = {...}) { Text(...) }`.
