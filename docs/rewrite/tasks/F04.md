# F04 — App shell: adaptive navigation + MainActivity in Compose

## Goal
`MainActivity` stops using ViewPager, fragments, and XML and renders `ClockApp()` with `setContent`. `ClockApp` is the
expressive shell: four top-level tabs (Clock, Alarm, Stopwatch, Timer) with a **`ShortNavigationBar`** on phones and a
**`WideNavigationRail`** on wide windows (≥ 600dp), a shared flexible top app bar component, and tab content
via navigation-compose. The tab screens themselves are **placeholders** in this task (F05+ replaces them).

The PM already moved the old fragments, `ViewPagerAdapter`, and their layouts to `docs/rewrite/legacy/` (not compiled).
`MainActivity.kt` currently does not compile; you will rewrite it.

### `ui/navigation/Routes.kt`

### `ui/navigation/ClockTopAppBar.kt`
```kotlin

fun ClockTopAppBar(
```

`LargeFlexibleTopAppBar` (title in `displaySmallEmphasized` if the API allows a styled title; otherwise the default)
with `actions` followed by an overflow `IconButton` (`Icons.Rounded.MoreVert`) opening a `DropdownMenu` with
Settings (`org.fossify.commons.R.string.settings`) and About (`org.fossify.commons.R.string.about`) items, each with a
leading icon. Colors: container `surface`, scrolled container `surfaceContainer`. Every tab screen will put this in
its own `Scaffold(topBar = …)` together with `Modifier.nestedScroll(scrollBehavior.nestedScrollConnection)`.

### `ui/navigation/ClockApp.kt`
```kotlin
@Composable
fun ClockApp(
    startTab: ClockTab,
    tabRequests: Flow<ClockTab>,              // tabs requested by new intents
    onTabChanged: (ClockTab) -> Unit,         // activity persists config.lastUsedViewPagerPage
    onOpenSettings: () -> Unit,
    onOpenAbout: () -> Unit,
)
```
- `rememberNavController()`, `NavHost(startDestination = startTab.route())` with the four tab routes, each rendering
  `TabPlaceholder(tab, onOpenSettings, onOpenAbout)` for now.
- Tab switching: `navigate(route) { popUpTo(graph.findStartDestination().id) { saveState = true }; launchSingleTop = true; restoreState = true }`.
- Transitions between tabs: fade-through, i.e. `fadeIn(motionScheme.defaultEffectsSpec()) + scaleIn(initialScale = 0.96f, spatial spec)`
  togetherWith `fadeOut(...)`. Get the specs from `MaterialTheme.motionScheme` inside the composable and pass them to the NavHost
  `enterTransition`/`exitTransition` lambdas.
- Collect `tabRequests` in a `LaunchedEffect` and navigate.
- Width ≥ 600dp (use `LocalWindowInfo.current.containerSize` + `LocalDensity`): `Row { WideNavigationRail(...) ; NavHost }`
  with `WideNavigationRailItem`s (rail collapsed, icon + label). Otherwise `Scaffold(bottomBar = { ShortNavigationBar { ShortNavigationBarItem… } })`.
  Selected items use `selectedIcon`; icon changes crossfade. Tap on an already selected tab does nothing.
- Haptic `HapticFeedbackType.SegmentTick` on tab change.
- Set `contentWindowInsets` correctly so content is edge-to-edge but not hidden behind system bars.

### Rewrite `activities/MainActivity.kt`
Still `class MainActivity : SimpleActivity()`. In `onCreate`: `enableEdgeToEdge()`, then
`setContent { ClockTheme { ClockApp(...) } }`. Port these behaviours from the legacy file **exactly**:
`appLaunched(BuildConfig.APPLICATION_ID)`, `updateWidgets()`, `migrateFirstDayOfWeek()`, background
`alarmController.rescheduleEnabledAlarms()`, the enabled-alarms → `handleFullScreenNotificationsPermission` toast,
`checkShortcuts()` + `getLaunchStopwatchShortcut()`, keep-screen-on in `onResume`/`onPause`, saving
`config.lastUsedViewPagerPage` (store the tab **index** = `ClockTab.ordinal`, as before), `launchAbout()` (unchanged,
keep the commons About screen for now), settings → `startActivity(Intent(this, SettingsActivity::class.java))`.
Start tab: the `OPEN_TAB` extra if present, else `config.defaultTab`. The old `getTabIndex` fallback means the
`lastUsedViewPagerPage` index is used when defaultTab is not one of the 4 ids, so keep that logic.
Intent extras: if `OPEN_TAB == TAB_STOPWATCH` set `config.toggleStopwatch = intent.getBooleanExtra(TOGGLE_STOPWATCH, false)`
(as the old code did). `onNewIntent` emits the tab into a `MutableSharedFlow<ClockTab>(extraBufferCapacity = 1)`
passed as `tabRequests`, and also sets `config.toggleStopwatch = true` when `TOGGLE_STOPWATCH` is true.
Store `TIMER_ID` from intents in a public `companion object { val requestedTimerId = MutableStateFlow(INVALID_TIMER_ID) }`
(timer screen F13 will consume it). Drop `onActivityResult`/`storeNewAlarmSound`, `setupTabs`, colors, and
`updateClockTabAlarm` (no longer needed).
