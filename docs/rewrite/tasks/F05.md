# F05 — Clock tab: ClockViewModel + ClockScreen

## Goal
Replace the Clock tab placeholder with a real, expressive Clock screen: a **hero digital clock** with animated
digits in Google Sans Flex, the date, a "next alarm" chip, and the list of selected world-clock time zones as an
expressive segmented list. Behaviour parity with `docs/rewrite/legacy/fragments/ClockFragment.kt` and
`docs/rewrite/legacy/adapters/TimeZonesAdapter.kt` (time-zone row rendering only; add/edit/delete is F07).

## Create

### `ui/clock/ClockViewModel.kt` — `class ClockViewModel(app: Application) : AndroidViewModel(app)`
- `val now: StateFlow<Long>` — a `flow { while (true) { emit(System.currentTimeMillis()); delay(1000 - System.currentTimeMillis() % 1000) } }`
  `.stateIn(viewModelScope, SharingStarted.WhileSubscribed(5_000), System.currentTimeMillis())`
  (ticks exactly on second boundaries, only while the UI collects it).
- `val nextAlarm: StateFlow<String>` (empty = none) — `refreshNextAlarm()` calls
  `context.getClosestEnabledAlarmString { … }` (it already runs the DB query off the main thread and calls back on main).
- `val timeZones: StateFlow<List<TimeZoneUi>>` — `combine(now, selectedZones)`. `selectedZones` is a
  `MutableStateFlow<List<MyTimeZone>>`, reloaded by `refreshTimeZones()` on `Dispatchers.IO` from
  `config.selectedTimeZones` + `getAllTimeZonesModified()` (same filter as the fragment).
- `data class TimeZoneUi(val id: Int, val title: String, val time: String, val amPm: String?, val dayLabel: String?, val offsetLabel: String)`
  — compute it as the adapter did (raw offset + DST). `time` comes from `getFormattedTime(passedSeconds, false, false).toString()`;
  split a trailing " AM"/" PM" into `amPm` when 12h. `dayLabel` is the formatted date only when it differs from today's.
  `offsetLabel` is the difference to local time, e.g. "+5 h", "−3:30 h", or "Same time" (new string
  `m3e_same_time`).
- `fun refresh()` = refreshNextAlarm() + refreshTimeZones(); the screen calls it on `ON_RESUME`
  (`LifecycleEventEffect(Lifecycle.Event.ON_RESUME)` from lifecycle-runtime-compose).
- Register on EventBus in `init` (`EventBus.getDefault().register(this)`), unregister in `onCleared`, and add
  `@Subscribe(threadMode = ThreadMode.MAIN) fun onAlarmRefresh(event: AlarmEvent.Refresh) = refreshNextAlarm()`.
- `val use24h: Boolean get() = config.use24HourFormat`.

### `ui/clock/HeroClock.kt` — `@Composable fun HeroClock(nowMillis: Long, use24h: Boolean, modifier: Modifier = Modifier)`
The visual centerpiece:
- Hours and minutes in `ClockTextStyles.heroClock` via `AnimatedTimeText` (`"HH:mm"` or `"h:mm"`), color `onSurface`.
- Seconds in a small pill next to the time (or below on narrow widths): a `Surface(shape = CircleShape (pill),
  color = primaryContainer)` with `AnimatedTimeText("ss", style = titleLargeEmphasized)`.
- 12h mode: AM/PM text (`labelLargeEmphasized`, `primary`) stacked above the seconds pill.
- **Breathing weight**: the hero font weight subtly animates between 350 and 450 every second
  (`ClockTextStyles.heroWith(weight)` + `animateIntAsState` keyed on the seconds parity, spec `motionScheme.slowEffectsSpec()`).
  If `heroWith` is too expensive (new FontFamily per frame), only use weights from a remembered set of 3 styles.
- Use `java.time` (`Instant.ofEpochMilli(nowMillis).atZone(ZoneId.systemDefault())`) and `DateTimeFormatter` for the strings.

### `ui/clock/ClockScreen.kt` — `@Composable fun ClockScreen(onOpenSettings: () -> Unit, onOpenAbout: () -> Unit,
onOpenAlarms: () -> Unit, onAddTimeZone: () -> Unit, viewModel: ClockViewModel = viewModel())`
- `Scaffold` with `ClockTopAppBar(title = stringResource(R.string.clock), scrollBehavior, …)`
  (`exitUntilCollapsedScrollBehavior()`), `floatingActionButton = MediumFloatingActionButton(onClick = onAddTimeZone)`
  with `Icons.Rounded.Public` (or `AddLocationAlt`) and a contentDescription (`R.string.add_timezone`, or a new
  `m3e_add_time_zone` if it does not exist — grep `strings.xml`).
- `LazyColumn` (nested scroll connected):
  1. item: `HeroClock`, centered, top padding 24.dp.
  2. item: date (`getFormattedDate(Calendar.getInstance())`, recompute when the day changes) in `titleLarge`, `onSurfaceVariant`, centered.
  3. item (when `nextAlarm` is not empty): `AssistChip(onClick = onOpenAlarms, leadingIcon = Alarm icon, label = nextAlarm)`,
     centered, using `MaterialTheme.shapes.large`, container `secondaryContainer`.
  4. If time zones exist: `SectionHeader(stringResource(R.string.time_zones or m3e_world_clock))` + `segmentedGroup(count)`
     where each row is `SegmentedListItem(onClick = {}, shapes = shapes, leadingContent = { ShapeBadge(MaterialShapes.Cookie6Sided, size = 48.dp) { offset text labelSmall } },
     supportingContent = { dayLabel / offsetLabel }, trailingContent = { time in titleLargeEmphasized + amPm }) { Text(title) }`.
  5. Bottom spacer of 96.dp so the FAB does not cover the last row.
- Enter animation: the hero clock scales in from 0.92 with a spatial spring on first composition.

Route `ClockRoute` → `ClockScreen(onOpenSettings, onOpenAbout, onOpenAlarms = { navigate to ALARM tab }, onAddTimeZone = {})`.
`onAddTimeZone` is wired in F07, so leave a `// F07` comment.

## Acceptance criteria
- [ ] `tools/agents/compile.sh` → `COMPILE OK`
- [ ] Time ticks every second, aligned to the second; ticking stops when the app is in the background (WhileSubscribed).
- [ ] 12/24h respected; date and next alarm shown; next alarm refreshes on resume and on `AlarmEvent.Refresh`.
- [ ] Time-zone rows show the correct local time, a day label when the day differs, and the offset.
- [ ] No DB or IO on the main thread. EventBus unregistered in `onCleared`.
