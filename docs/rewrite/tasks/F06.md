# F06 — Expressive analogue clock + digital/analogue toggle

## Goal
Add an expressive analogue clock face and let the user switch between it and the digital hero clock by tapping the
clock. The choice persists.

## Read first
- `app/src/main/kotlin/org/fossify/clock/ui/clock/ClockScreen.kt`, `ui/clock/HeroClock.kt` (signature + how it is placed)
- `app/src/main/kotlin/org/fossify/clock/helpers/Config.kt` (last 20 lines) and `helpers/Constants.kt` (grep `m3e_`)
- `ui/components/Shapes.kt` (signatures only)

## Implement

### Config
`const val CLOCK_FACE_STYLE = "m3e_clock_face_style"` in Constants.kt (`CLOCK_FACE_DIGITAL = 0`, `CLOCK_FACE_ANALOGUE = 1`)
and `var clockFaceStyle: Int` (default digital) in Config.kt.

### `ui/clock/AnalogClock.kt` — `@Composable fun AnalogClock(nowMillis: Long, modifier: Modifier = Modifier)`
Pixel-style expressive dial, square aspect ratio, max 280.dp:
- **Dial**: `MaterialShapes.Cookie12Sided` filled with `surfaceContainerHigh`, slowly rotating (`RotatingShape`-like, one
  turn per 60 s). Render the shape in a background layer so the hands and markers do not rotate with it.
- **Markers**: 12 small dots at 82% radius (`outlineVariant`), with the 12/3/6/9 dots larger and in `primary`.
- **Hour hand**: thick (14.dp) rounded line, `primary`, length 50% radius.
- **Minute hand**: 10.dp, `tertiary`, length 72% radius.
- **Second hand**: 3.dp line + 10.dp circle at its tip, `secondary`, length 82%.
- Hand angles from `java.time` local time. The second hand **ticks** to each new second with a springy overshoot
  (`spring(dampingRatio = 0.45f, stiffness = Spring.StiffnessMedium)`). To avoid the 59→0 backwards spin, keep an
  ever-increasing angle: `remember { mutableFloatStateOf(...) }` and add the delta modulo 360 every tick, then animate with `Animatable`.
- Center cap: 16.dp circle in `primary` with a 6.dp `onPrimary` dot.
- Draw everything with one `Canvas` (except the dial background). Add semantics `contentDescription` = the formatted time.

### `ClockScreen` / `HeroClock`
- Wrap the hero area in `AnimatedContent(targetState = faceStyle)` with transition
  `(fadeIn + scaleIn(initialScale = 0.85f)) togetherWith (fadeOut + scaleOut(targetScale = 1.1f))`, using spatial specs from
  `MaterialTheme.motionScheme`.
- A tap on the clock (`Modifier.clickable(interactionSource, indication = null)` + a `pressSquish`) toggles the style and
  persists it via a ViewModel method `toggleFaceStyle()` that writes `config.clockFaceStyle`. Add haptic feedback.
- Add an `onClickLabel` for accessibility (new string `m3e_switch_clock_style`).

## Acceptance criteria
- [ ] `tools/agents/compile.sh` → `COMPILE OK`
- [ ] Analogue face shows the correct time, the second hand never spins backwards at :00, and the dial rotates independently of the hands.
- [ ] Tap toggles with an expressive transition; the choice survives an app restart.
