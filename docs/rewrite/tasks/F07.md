# F07 — World clock management: add zones sheet, rename, swipe to remove

## Goal
Make the time-zone list on the Clock screen editable, replacing `AddTimeZonesDialog`, `EditTimeZoneDialog`, and the CAB
delete in `TimeZonesAdapter`:
1. FAB → **add-zones bottom sheet** with search and multi-select.
2. Tap on a zone row → **rename dialog** (empty title = reset to default).
3. **Swipe to remove** a zone, with an Undo snackbar.

## Implement

### `ClockViewModel` additions
- `fun setSelectedZones(ids: Set<Int>)` → `config.selectedTimeZones = ids.map { it.toString() }.toHashSet()`, then refresh.
- `fun removeZone(id: Int)` and `fun restoreZone(id: Int)` (for Undo).
- `fun renameZone(id: Int, newTitle: String)` — exactly the old `EditTimeZoneDialog.dialogConfirmed` logic
  (`getEditedTimeZonesMap()`, remove the entry when blank, write back `config.editedTimeZoneTitles` with `EDITED_TIME_ZONE_SEPARATOR`).
- `val allZones: List<ZoneOption>` built lazily: `data class ZoneOption(val id: Int, val city: String, val gmtOffset: String, val zoneName: String)`
  — split the `getAllTimeZones()` title at the first space: `"GMT-11:00"` / `"Midway"`.

### `ui/clock/AddTimeZonesSheet.kt`
`@Composable fun AddTimeZonesSheet(all: List<ZoneOption>, initiallySelected: Set<Int>, onConfirm: (Set<Int>) -> Unit, onDismiss: () -> Unit)`
- `ModalBottomSheet` (`skipPartiallyExpanded = true`) with a title, a search field
  (`SearchBarDefaults.InputField` or an `OutlinedTextField` with `Icons.Rounded.Search`, shape `CircleShape`) that filters
  by city or GMT text, case-insensitive.
- `LazyColumn` of rows: leading `ShapeBadge(MaterialShapes.Pill or Cookie4Sided, size = 40.dp)` with the GMT offset
  (labelSmall, e.g. "−11"), city as headline, and a trailing `Checkbox`. Whole row toggles (`Modifier.toggleable`).
  Selected rows use `secondaryContainer` background via `SegmentedListItem(checked=…, onCheckedChange=…)` if that
  overload fits (see ListItem.md); otherwise a `ListItem` with an animated background color.
- Bottom bar: count of selected + `Button(shapes = ButtonDefaults.shapes())` "OK" (`org.fossify.commons.R.string.ok`) → `onConfirm`.

### `ui/clock/RenameTimeZoneDialog.kt`
`@Composable fun RenameTimeZoneDialog(currentTitle: String, defaultTitle: String, onConfirm: (String) -> Unit, onDismiss: () -> Unit)`
— `AlertDialog`, an `OutlinedTextField` prefilled with `currentTitle`, `defaultTitle` shown as supporting text, focus and
keyboard requested on open (`FocusRequester` + `LaunchedEffect`), and an "OK" and "Cancel" pair.

### `ClockScreen` changes
- FAB `onClick` opens `AddTimeZonesSheet` (local `rememberSaveable` state); `onAddTimeZone` parameter can be removed
  (then update `ClockApp.kt`).
- Each time-zone row is wrapped in a `SwipeToDismissBox`. Both directions remove the zone; the background is
  `errorContainer` with a delete icon that scales in as the swipe progresses. Then show a `SnackbarHostState`
  snackbar "Removed <title>" with an Undo action (`org.fossify.commons.R.string.undo`) → `restoreZone`.
  Add `SnackbarHost` to the Scaffold. Use `Modifier.animateItem()` on rows.
- Row `onClick` → `RenameTimeZoneDialog`.
