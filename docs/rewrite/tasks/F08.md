# F08 — Alarm tab: AlarmViewModel + alarm list

## Goal
Replace the Alarm tab placeholder with the expressive alarm list. Port **all** logic from
`docs/rewrite/legacy/fragments/AlarmFragment.kt` and the list parts of `app/src/main/kotlin/org/fossify/clock/adapters/AlarmsAdapter.kt`
(sorting, toggling with the recurring-alarm warning, one-shot handling, multi-select delete). The editor is F10, the sort
dialog and reorder are F11: here, tapping an alarm or the FAB calls callbacks that are left as TODO.

## Create

### `ui/alarm/AlarmViewModel.kt` — `AndroidViewModel`
- `val alarms: StateFlow<List<Alarm>>` — loaded on `Dispatchers.IO` with **exactly** the sort logic of `getSortedAlarms`
  (alarm time / date created / date and time / custom order from `config.alarmsCustomSorting`).
- `val selection: StateFlow<Set<Int>>` + `toggleSelection(id)`, `clearSelection()`, `selectAll()`.
- `fun deleteSelected()` → `dbHelper.deleteAlarms(...)` on IO (it cancels scheduled alarms), post `AlarmEvent.Refresh`,
  `updateWidgets()`, reload.
- `fun setEnabled(alarm: Alarm, enabled: Boolean)`: port `toggleAlarm` + `alarmToggled` + `checkAlarmState`:
  non-recurring → `updateNonRecurringAlarmDay(alarm)` + `dbHelper.updateAlarm(alarm)`; then
  `dbHelper.updateAlarmEnabledState`; enabled → `alarmController.scheduleNextOccurrence(alarm, showToasts = true)`
  (on the **main** thread, because it shows toasts), else `cancelAlarmClock(alarm)`; a one-shot alarm that is disabled is deleted;
  `updateWidgets()`; reload. Unknown error → toast `org.fossify.commons.R.string.unknown_error_occurred`.
- The recurring-alarm warning (`config.wasAlarmWarningShown`, message `org.fossify.commons.R.string.alarm_warning`) is UI:
  expose `fun needsRecurringWarning(alarm) = alarm.isRecurring() && !config.wasAlarmWarningShown` and
  `fun markWarningShown()`.
- The full-screen-notification permission check stays in the Activity: the screen receives a
  `requestAlarmPermission: (onResult: (Boolean) -> Unit) -> Unit` lambda (MainActivity implements it with
  `handleFullScreenNotificationsPermission`). On denial, reload so the switch flips back.
- `fun newAlarmTemplate(): Alarm` = `createNewAlarm(DEFAULT_ALARM_MINUTES, 0).apply { isEnabled = true; days = getTomorrowBit() }`.
- EventBus: register in `init`, unregister in `onCleared`, `@Subscribe(MAIN) AlarmEvent.Refresh` → reload.
- `fun daysText(alarm: Alarm): String` — port `getAlarmSelectedDaysString`.

### `ui/alarm/WeekdayDots.kt` — `@Composable fun WeekdayDots(days: Int, modifier: Modifier = Modifier, enabled: Boolean = true)`
Seven 22.dp circles ordered by `config.firstDayOfWeek` (use `context.rotateWeekdays(...)` / the day bit constants in
`Constants.kt`). Each circle contains the one-letter weekday (`org.fossify.commons.R.array.week_day_letters` if it exists,
else the first letter of `DayOfWeek.getDisplayName(TextStyle.NARROW, locale)`). Selected days are filled `primary` with
`onPrimary` letters; others use an `outlineVariant` outline. When disabled, everything is 38% alpha.

### `ui/alarm/AlarmCard.kt` — `@Composable fun AlarmCard(alarm: Alarm, daysText: String, use24h: Boolean, selected: Boolean,
selectionMode: Boolean, onClick: () -> Unit, onLongClick: () -> Unit, onToggle: (Boolean) -> Unit, modifier: Modifier = Modifier)`
- `Card` with `MaterialTheme.shapes.extraLarge` and `Modifier.combinedClickable`. Container: enabled → `surfaceContainerHigh`,
  disabled → `surfaceContainerLow`; selected → `secondaryContainer` with a 2.dp `primary` border. Animate the color.
- Row: left column = time (`ClockTextStyles.listTime`, 12h: smaller AM/PM next to it), label (`titleMedium`, if not empty),
  then `WeekdayDots` for recurring alarms or `daysText` for one-shot alarms. Right: an expressive `Switch` whose thumb shows
  `Icons.Rounded.Check` / `Icons.Rounded.Close` (`thumbContent`). In selection mode the switch is replaced by a checkbox-like
  `ShapeBadge` (Cookie4Sided when selected).
- Disabled alarms: time and label at 60% alpha. Scale animation on press (`pressSquish`).

### `ui/alarm/AlarmScreen.kt` — `@Composable fun AlarmScreen(onOpenSettings, onOpenAbout, onEditAlarm: (Alarm) -> Unit,
onSortClick: () -> Unit, requestAlarmPermission: ((Boolean) -> Unit) -> Unit, viewModel: AlarmViewModel = viewModel())`
- Normal mode: `ClockTopAppBar(title = alarm string, actions = { sort IconButton (Icons.AutoMirrored.Rounded.Sort, `org.fossify.commons.R.string.sort_by`) })`.
- Selection mode (selection not empty): `TopAppBar` with a close icon (clear selection), "N selected", a select-all action,
  and a delete action (show `ConfirmDialog` first). `BackHandler` clears the selection.
- Body: `LazyColumn` (contentPadding 16.dp, spacing 12.dp, `animateItem()`, key = alarm.id) of `AlarmCard`s;
  empty → `ExpressiveEmptyState(icon = Icons.Rounded.AlarmAdd, title = R.string.no_alarms_found or a new m3e string,
  polygon = MaterialShapes.Sunny)`.
- FAB: `LargeFloatingActionButton` (or `MediumFloatingActionButton` if Large does not exist) with `Icons.Rounded.Add`,
  hidden in selection mode (`AnimatedVisibility` scale), → `onEditAlarm(viewModel.newAlarmTemplate())`.
- Toggle flow: if `needsRecurringWarning` → `ConfirmDialog` (OK only) → `markWarningShown()` then proceed;
  proceed = `requestAlarmPermission { granted -> if (granted) setEnabled(...) else reload() }`.
- `LifecycleEventEffect(ON_RESUME) { viewModel.reload() }`.

- `ClockApp.kt`: `AlarmRoute` → `AlarmScreen(...)`. Add a parameter `requestAlarmPermission` to `ClockApp` and pass it from
