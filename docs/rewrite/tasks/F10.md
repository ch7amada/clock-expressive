# F10 — Alarm editor (Compose replacement for `EditAlarmDialog`)

## Goal
An expressive full-height editor sheet used to create and edit alarms, opened from the Alarm screen (FAB and card tap).
Port **every** behaviour of `app/src/main/kotlin/org/fossify/clock/dialogs/EditAlarmDialog.kt`.

## Create `ui/alarm/AlarmEditorSheet.kt`
```kotlin
@Composable
fun AlarmEditorSheet(
    initial: Alarm,               // id == 0 → new alarm
    use24h: Boolean,
    onSave: (Alarm) -> Unit,      // caller persists and schedules
    onDelete: ((Alarm) -> Unit)?, // null for new alarms
    onDismiss: () -> Unit,
)
```
Hold the edit state in `rememberSaveable` fields (time minutes, days, label, vibrate, soundTitle, soundUri). Mutate a copy, never `initial`.
- **New alarm**: apply `restoreLastAlarm()` semantics from `config.alarmLastConfig` (the caller passes the template; the sheet
  applies last config only when `initial.id == 0`).
- **Header**: a big tappable time (`ClockTextStyles.heroClockCompact`) inside a `Surface(shape = extraLarge, color = primaryContainer)`.
  Tapping it expands an inline M3 `TimePicker(state = rememberTimePickerState(h, m, is24Hour = use24h))` with a toggle `IconButton`
  to switch to `TimeInput` (keyboard). Changes apply live. Below the time, the "(Today)"/"(Tomorrow)" label for
  non-recurring alarms (same rule as `checkDaylessAlarm`).
- **Days**: a `ButtonGroup`-style row of 7 `ToggleButton`s in **connected** style (leading, middle, and trailing shapes from
  `ButtonGroupDefaults.connected*ButtonShapes()`), ordered with `context.rotateWeekdays(listOf(0..6))`, labelled with
  `org.fossify.commons.R.array.week_day_letters`. Keep the toggling logic of the old code (a non-recurring alarm resets `days` to 0 before the first
  toggle; `addBit`/`removeBit` from commons). Selected buttons morph to a rounder shape (default `ToggleButton` checked shape) and use
  `primary`. If `ButtonGroup` does not fit 7 items on narrow screens, use a plain `Row` with `Arrangement.spacedBy(2.dp)` + `weight(1f)`.
- **Label**: `OutlinedTextField` with a leading `Icons.Rounded.Label` icon, single line, `org.fossify.commons.R.string.label`.
- **Sound**: a `SegmentedListItem` row (leading `Icons.Rounded.MusicNote` inside a `ShapeBadge(MaterialShapes.Cookie4Sided, 40.dp)`)
  showing `soundTitle`; click → `SoundPickerSheet(type = RingtoneManager.TYPE_ALARM, loopPreview = true)`; `onSoundDeleted` resets to
  `getDefaultAlarmSound(TYPE_ALARM)` if it was the current one (as in the old code).
- **Vibrate**: a `SegmentedListItem(checked = …, onCheckedChange = …)` with a trailing `Switch`.
- **Actions** (sticky bottom row): for existing alarms an `OutlinedButton` "Delete" (`org.fossify.commons.R.string.delete`, error color),
  then a `Button(shapes = ButtonDefaults.shapes())` "Save" (`org.fossify.commons.R.string.save`).
- Save flow: if `!config.wasAlarmWarningShown` → `ConfirmDialog` (alarm_warning, OK only) → set the flag → continue; then build the result
  alarm: `updateNonRecurringAlarmDay(alarm)`, `isEnabled = true`, `oneShot = false`, label trimmed → `onSave(result)`.

## `AlarmViewModel` additions
`fun saveAlarm(alarm: Alarm, onDone: () -> Unit)` — on IO: insert (`id == 0`, then set `alarm.id` from the returned id;
`-1` → error toast) or update (false → error toast); `config.alarmLastConfig = alarm`; then on Main:
`alarmController.scheduleNextOccurrence(alarm, showToasts = true)`, `updateWidgets()`, post `AlarmEvent.Refresh`, reload, `onDone()`.
`fun deleteAlarm(alarm: Alarm)` — `dbHelper.deleteAlarms(arrayListOf(alarm))` on IO, refresh, and widgets.

## `AlarmScreen` wiring
Replace the `onEditAlarm` parameter with internal state `var editing by remember { mutableStateOf<Alarm?>(null) }`. FAB → `editing = viewModel.newAlarmTemplate()`;
card tap (not in selection mode) → `editing = alarm.copy()`. Show `AlarmEditorSheet` when not null. On save: `requestAlarmPermission { granted -> if (granted) viewModel.saveAlarm(it) { editing = null } }`
(the old code checked the permission before saving). Update `ClockApp.kt` for the removed parameter.
