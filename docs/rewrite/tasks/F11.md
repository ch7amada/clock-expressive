`ChangeTimerSortDialog`), and add **drag-to-reorder** in selection mode (the old adapters showed a drag handle in selection
mode and switched to custom sorting on move).

## Reorderable library (`sh.calvin.reorderable:reorderable:3.1.0`, already a dependency) — verified API
```kotlin
val lazyListState = rememberLazyListState()
val reorderState = rememberReorderableLazyListState(lazyListState) { from, to ->
    // from.key / to.key are the item keys, from.index / to.index the indexes
    list = list.toMutableList().apply { add(to.index, removeAt(from.index)) }
}
LazyColumn(state = lazyListState) {
    items(list, key = { it.id }) { item ->
        ReorderableItem(reorderState, key = item.id) { isDragging ->
            val elevation by animateDpAsState(if (isDragging) 8.dp else 0.dp)
            Card(...) { Icon(Icons.Rounded.DragHandle, null, Modifier.draggableHandle(onDragStopped = { persist() })) }
        }
    }
}
```
Imports: `sh.calvin.reorderable.ReorderableItem`, `sh.calvin.reorderable.rememberReorderableLazyListState`. `draggableHandle` is an
extension available inside the `ReorderableItem` content scope (`ReorderableCollectionItemScope`).
`ReorderableItem(state, key, modifier, enabled, animateItemModifier = Modifier.animateItem(), content)` already applies
`animateItem()`, so remove your own `Modifier.animateItem()` from cards wrapped in it. Pass `enabled = selectionMode`.
Index offsets: if the LazyColumn has non-reorderable items before the cards (headers), subtract them.

## Implement
1. Sort dialogs: `RadioListDialog` with the alarm options (creation order, alarm time, day and alarm time, custom) and the timer options (creation order →
   `SORT_BY_DATE_CREATED`, timer duration, custom), exactly mirroring the old mapping. Selecting writes `config.alarmSort` / `config.timerSort`
   and reloads. Show from the screens' sort action; remove the `onSortClick` parameters (internal state) and update `ClockApp.kt`.
2. Drag reorder in **selection mode** only: each card shows a drag handle (`Icons.Rounded.DragIndicator`, contentDescription new `m3e_reorder`)
   instead of the selection badge's position. While dragging, the card scales to 1.03, raises elevation, and uses `surfaceContainerHighest`
   (expressive lift). The ViewModels get `fun moveAlarm(from: Int, to: Int)` (in-memory list update) and `fun persistCustomOrder()`, which writes
   `config.alarmsCustomSorting` = ids joined with ", " (the same format the sort code parses) and sets `config.alarmSort = SORT_BY_CUSTOM`.
   The same for timers (`timersCustomSorting`, `timerSort`). Haptic `SegmentTick` when an item crosses another.
