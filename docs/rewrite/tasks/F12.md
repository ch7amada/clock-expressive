# F12 — Stopwatch tab

## Goal
Replace the Stopwatch tab placeholder with an expressive stopwatch. Port **all** behaviour from
`docs/rewrite/legacy/fragments/StopwatchFragment.kt` (291 lines). The `helpers/Stopwatch.kt` singleton, `StopwatchService`,
and the `Lap` model stay unchanged.

## Read first
- `docs/rewrite/legacy/fragments/StopwatchFragment.kt` (all of it)
- `app/src/main/kotlin/org/fossify/clock/helpers/Stopwatch.kt` (155 lines), `models/Lap.kt`, `extensions/Long.kt` (`formatStopwatchTime`)
- `app/src/main/kotlin/org/fossify/clock/ui/navigation/ClockApp.kt`
- signatures (grep `fun `): `ui/components/Shapes.kt` (`MorphingPlayPauseButton`), `ui/components/AnimatedTimeText.kt`,
  `ui/components/EmptyState.kt`, `ui/theme/Type.kt`
- `docs/rewrite/api/WavyProgressIndicator.md` (`CircularWavyProgressIndicator`), `docs/rewrite/api/FloatingToolbar.md`
  (grep `HorizontalFloatingToolbar`), `docs/rewrite/api/SegmentedButton.md` or `ToggleButton.md` (for the sort chips)

## Create

### `ui/stopwatch/StopwatchViewModel.kt` — `ViewModel`
- Implements `Stopwatch.UpdateListener`: `addUpdateListener` in `init`, `removeUpdateListener` in `onCleared`.
- `data class StopwatchUiState(val totalTime: Long, val lapTime: Long, val useLongerMSFormat: Boolean, val state: Stopwatch.State, val laps: List<Lap>, val sorting: Int)`
  exposed as `StateFlow`. `laps` = `Stopwatch.laps` + the live lap (`STOPWATCH_LIVE_LAP_ID`) while not stopped, sorted with
  `Lap.sorting` (as `updateLaps()` did; computed on `Dispatchers.Default`).
- `fun toggle()`, `fun lap()`, `fun reset()`, and `fun changeSorting(clickedValue: Int)` (same flip-bit logic; persists `config.stopwatchLapsSort`
  and `Lap.sorting`). On init: `Lap.sorting = config.stopwatchLapsSort`.
- `fun consumeToggleRequest(): Boolean` — if `config.toggleStopwatch`, set it to false and return true (screen then starts the stopwatch
  if it is STOPPED, like `startStopWatch()`).
- Also extract `fastest`/`slowest` lap ids (only when ≥ 2 completed laps) for highlighting.

### `ui/stopwatch/StopwatchScreen.kt` — `@Composable fun StopwatchScreen(onOpenSettings, onOpenAbout, requestNotificationPermission: ((Boolean) -> Unit) -> Unit, viewModel: StopwatchViewModel = viewModel())`
- `Scaffold` + `ClockTopAppBar(title = R.string.stopwatch)`.
- **Hero dial** (centered, 280.dp max, square):
  - A `CircularWavyProgressIndicator` showing the progress of the current minute (`(totalTime % 60_000) / 60_000f`), track
    `surfaceContainerHighest`, indicator `primary`; amplitude only while RUNNING (use the indicator's `amplitude` parameter if
    present in the API doc; otherwise accept the default).
  - Inside it: the time via `AnimatedTimeText(totalTime.formatStopwatchTime(useLongerMSFormat), style = ClockTextStyles.timer)`,
    and below it the current lap time (`titleMedium`, `onSurfaceVariant`) once laps exist.
  - Paused state: the time text gently blinks (alpha 1 → 0.4, infinite, `slowEffectsSpec`), as in Google Clock.
- **Controls** (bottom, centered): a `HorizontalFloatingToolbar(expanded = true)` holding: Reset `IconButton` (visible when not STOPPED),
  the `MorphingPlayPauseButton(isRunning = state == RUNNING, size = 88.dp)` in the middle, and a Lap `FilledTonalIconButton` (visible when RUNNING,
  `Icons.Rounded.Flag`). Animate visibility with scale and fade. Content descriptions from strings (`R.string.lap` exists; reset → grep or `m3e_reset`).
  If `HorizontalFloatingToolbar` is awkward, use a `Row` inside a `Surface(shape = CircleShape, color = surfaceContainerHigh, tonalElevation)`.
- Toggle requires the notification permission: `requestNotificationPermission { granted -> if (granted) viewModel.toggle() }`
  (MainActivity passes `handleNotificationPermission` plus the `PermissionRequiredDialog` fallback, exactly as the old fragment did).
- **Laps** (only when laps exist): a header row with three sort `FilterChip`s/`ToggleButton`s "#", "Lap", and "Total" (labels from strings:
  grep `lap`, `lap_time`, `total_time`, or add `m3e_`), with an arrow icon showing the direction. Click → `changeSorting(SORT_BY_LAP/...)`.
  Then a `LazyColumn` of lap rows: `ShapeBadge(MaterialShapes.Cookie4Sided, 36.dp)` with the lap number, lap time (`titleMedium`, tabular),
  total time (`bodyMedium`, `onSurfaceVariant`). The fastest lap row is tinted `tertiaryContainer` with a "Fastest" label, the slowest `errorContainer`
  with "Slowest" (new `m3e_` strings). The live lap row is shown in `primary` text. Rows use `animateItem()`; scroll to top when a lap is added.
- Phone portrait: dial on top, laps below, controls overlaid at the bottom. Width ≥ 600dp: dial left, laps right (`Row`).
- `LaunchedEffect(Unit)`: `if (viewModel.consumeToggleRequest() && state == STOPPED) toggle with permission` (shortcut and widget intents).
  Also re-check on `ON_RESUME` (`LifecycleEventEffect`), because MainActivity may set the flag for an already open screen.
- Haptics: `HapticFeedbackType.Confirm` on lap, `Reject` on reset.

### Wire up
`ClockApp`: `StopwatchRoute` → `StopwatchScreen(...)`; add a `requestNotificationPermission` parameter to `ClockApp`, implemented in MainActivity
with the old fragment's logic (`handleNotificationPermission` and, if denied, `PermissionRequiredDialog(..., allow_notifications_reminders, { openNotificationSettings() })`).
