## How timers work (do not change it)
`App.kt` listens to EventBus: `TimerEvent.Start(id, durationMs)` starts a `CountDownTimer` that writes
`TimerState.Running(duration, tick)` to Room every second and posts `TimerEvent.Refresh`; `Pause(id, durationMs)` → `Paused(duration, tick)`;
`Reset(id)` → `Idle` (a one-shot timer gets deleted); `Delete(id)`; finish → `Finished`. `timerHelper.getTimers { }` loads from Room
on a background thread and calls back on that thread. `Timer.seconds` is the configured duration. `tick` = remaining ms.

- `val timers: StateFlow<List<Timer>>` with the exact sort logic of `getSortedTimers` (duration / date created / custom order);
  `refresh()` is called on init, on `ON_RESUME`, and on `@Subscribe(MAIN) TimerEvent.Refresh` (register/unregister EventBus).
  Keep the first-launch workaround: if `config.appRunCount == 1`, refresh again after 1 s.
- `fun toggle(timer)`: same `when (state)` as `toggleTimer` (post Start/Pause events). `fun reset(timer)` → post `Reset` + `hideTimerNotification(id)`.

### `ui/timer/TimerCard.kt` — `@Composable fun TimerCard(timer: Timer, selected: Boolean, selectionMode: Boolean, onClick, onLongClick, onToggle, onReset, modifier)`
- `Card(shape = extraLarge)`; container `surfaceContainerHigh`; Running → `primaryContainer`; Finished → `tertiaryContainer` with a
  pulsing scale (1 → 1.02, infinite) to draw attention. Animate colors. Selected: `secondaryContainer` + `primary` border.
- Left: a 132.dp `Box` with `CircularWavyProgressIndicator(progress = { animatedProgress })`, where progress = remaining / total
  (Idle = 1f, Finished = 0f), animated linearly over 1 s between ticks so the ring moves smoothly. Wave amplitude only while Running.
  Inside the ring: the remaining time (`getFormattedDuration()` of `tick / 1000` rounded up; Idle shows `seconds`) in `titleLargeEmphasized` (tabular).
- Right column: the label (`titleMedium`, if any), the total duration (`bodyMedium`, `onSurfaceVariant`), and a row with
  the `MorphingPlayPauseButton(isRunning = state is Running, size = 64.dp)` and a Reset `FilledTonalIconButton(shapes = IconButtonDefaults.shapes())`
  (`Icons.Rounded.Replay`) that is visible only when Running/Paused/Finished.
- Selection mode: the buttons are replaced by a selection `ShapeBadge`, as in `AlarmCard`.

### `ui/timer/TimerScreen.kt` — `@Composable fun TimerScreen(onOpenSettings, onOpenAbout, onEditTimer: (Timer) -> Unit, onSortClick: () -> Unit, requestNotificationPermission: ((Boolean) -> Unit) -> Unit, viewModel: TimerViewModel = viewModel())`
