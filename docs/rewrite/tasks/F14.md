# F14 — Timer editor with an expressive duration keypad

## Goal
Replace `EditTimerDialog` and `MyTimePickerDialogDialog` with an expressive editor sheet built around a Google-Clock-style
**numeric keypad** for the duration (type digits → `hh mm ss` fills from the right), plus label, sound, and vibrate.

## Read first
- `app/src/main/kotlin/org/fossify/clock/dialogs/EditTimerDialog.kt` (111 lines) and `dialogs/MyTimePickerDialogDialog.kt` (42 lines)
- `app/src/main/kotlin/org/fossify/clock/ui/alarm/AlarmEditorSheet.kt` — **reuse its structure and style** (sheet, label field, sound row,
  vibrate row, bottom actions) so the two editors feel like one family
- `app/src/main/kotlin/org/fossify/clock/ui/timer/TimerViewModel.kt`, `ui/timer/TimerScreen.kt`
- signatures: `ui/components/SoundPicker.kt`, `ui/components/Shapes.kt`, `ui/theme/Type.kt`
- `docs/rewrite/api/Button.md` (grep `shapes(`), `docs/rewrite/api/IconButton.md`

## Create

### `ui/timer/DurationKeypad.kt`
1. `@Composable fun DurationDisplay(digits: String, modifier: Modifier = Modifier)` — shows `HHh MMm SSs` from a ≤6-char digit
   string padded left with zeros. Digits in `ClockTextStyles.timer`, unit letters in `titleLarge`; the groups the user has
   typed are `primary`, untyped zero groups are `onSurfaceVariant` at 50% alpha. A 2.dp underline below that animates its color.
2. `@Composable fun DurationKeypad(onDigit: (Char) -> Unit, onDoubleZero: () -> Unit, onBackspace: () -> Unit, modifier: Modifier = Modifier)`
   — a 4×3 grid: 1–9, "00", 0, ⌫. Each key is a large (≥ 72.dp) `FilledTonalButton`/`Button` with `shapes = ButtonDefaults.shapes()`
   (expressive: round at rest, squarer when pressed — this shape morph is the key expressive effect), `headlineMediumEmphasized` text.
   Backspace uses `Icons.AutoMirrored.Rounded.Backspace`, long-press clears all (pass an `onClear` param). Haptic `KeyboardTap` on each press.
3. `fun digitsToSeconds(digits: String): Int` and `fun secondsToDigits(seconds: Int): String` (pure functions; `"130"` → 1 m 30 s = 90 s;
   minutes/seconds may exceed 59 when typed, e.g. "90" seconds = 90, as Google Clock normalises). Add a `@Preview`.

### `ui/timer/TimerEditorSheet.kt`
```kotlin
@Composable
fun TimerEditorSheet(initial: Timer, onSave: (Timer) -> Unit, onDismiss: () -> Unit)
```
- `ModalBottomSheet(skipPartiallyExpanded = true)`. A new timer (`id == null`) applies `config.timerLastConfig` like `restoreLastAlarm()`.
- Top: `DurationDisplay` + `DurationKeypad` (keypad state = digit string in `rememberSaveable`, initialised from `secondsToDigits(seconds)`).
- Then: the label `OutlinedTextField`, the sound row (`SoundPickerSheet`, deleted-sound handling as in the old dialog; also set `channelId = null` when the
  sound changes), and the vibrate row (also sets `channelId = null`), styled exactly like `AlarmEditorSheet`.
- Save: `seconds = digitsToSeconds(...)`, `<= 0` → 10 (old rule); label; → `onSave(timer.copy(...))`. Save is a large
  `Button(shapes = ButtonDefaults.shapes())` with a "Start" variant: for **new** timers show two buttons, "Save" and "Save & start"
  (new `m3e_save_and_start` string), the latter also posting `TimerEvent.Start(id, seconds * 1000L)` after saving.

### `TimerViewModel` + `TimerScreen`
- `fun saveTimer(timer: Timer, start: Boolean, onDone: () -> Unit)` → `timerHelper.insertOrUpdateTimer(timer) { id -> config.timerLastConfig = timer; if (start) post Start(id.toInt(), …); post Refresh; onDone on Main }`.
- `TimerScreen`: replace `onEditTimer` with internal `editing` state (FAB → `newTimer()`, card tap → `copy()`); remove the param from `ClockApp`.
  "Save & start" must go through `requestNotificationPermission` first.
