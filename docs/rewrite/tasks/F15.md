# F15 — Ringing screen (AlarmActivity) + snooze picker in Compose

## Goal
The moment that matters most: when an alarm rings. Rewrite `AlarmActivity`'s UI in Compose as a bold, full-screen
Material 3 Expressive experience, and replace the View-based snooze picker (commons `showPickSecondsDialog`) in both
`AlarmActivity` and `SnoozeReminderActivity` with a Compose snooze sheet. **All non-UI behaviour stays identical.**

## Read first
- `app/src/main/kotlin/org/fossify/clock/activities/AlarmActivity.kt` (241 lines — all)
- `app/src/main/kotlin/org/fossify/clock/activities/SnoozeReminderActivity.kt` (43 lines)
- signatures: `ui/components/Shapes.kt`, `ui/components/AnimatedTimeText.kt`, `ui/theme/Theme.kt`, `ui/theme/Type.kt`
- `docs/rewrite/api/ModalBottomSheet.md`, `docs/rewrite/api/Button.md`
- Relevant layout and theme facts: AlarmActivity uses the app theme with `launchMode="singleTask"`; SnoozeReminderActivity uses
  `@style/Theme.Transparent` and extends `AppCompatActivity` (keep both as they are).

## Create

### `ui/ringing/RingingScreen.kt`
```kotlin
@Composable
fun RingingScreen(label: String, nowMillis: Long, use24h: Boolean, onDismiss: () -> Unit, onSnooze: () -> Unit)
```
- Background `surface`; centered, a **huge pulsing morphing shape** (~320.dp) behind the time: morph continuously between
  `MaterialShapes.Cookie9Sided` → `Sunny` → `Cookie12Sided` → `SoftBurst` (cycle with `rememberInfiniteTransition`, progress 0..1 per pair,
  using `Morph` + `MorphPolygonShape` from `Shapes.kt`), slowly rotating, scale pulsing 0.95↔1.05 (~1.2 s), filled `primaryContainer`.
- On top: the current time (`ClockTextStyles.heroClock`, `onPrimaryContainer`, `AnimatedTimeText`), the alarm label (`headlineSmallEmphasized`), and the date.
- Bottom: the **slide control** (`SlideToActionTrack`): a 96.dp-high pill track (`surfaceContainerHighest`) with a snooze icon (`Icons.Rounded.Snooze`)
  at the left end, a dismiss icon (`Icons.Rounded.AlarmOff`) at the right end, and a draggable 80.dp handle in the middle
  (`MaterialShapes.Cookie9Sided` shape, `primary`, `Icons.Rounded.Alarm` icon wiggling ±10° every second).
  Drag with `Modifier.draggable` / `anchoredDraggable` horizontally; the handle morphs toward a circle while dragged; the end icons scale
  up as the handle approaches. Reaching an end (within the 50px threshold of the old code) → haptic `LongPress` + `onDismiss()`/`onSnooze()`
  (only once). Releasing early springs back (`motionScheme.defaultSpatialSpec()`) and shows a hint text "Swipe left to snooze, right to dismiss"
  (reuse the old `R.string.reminder_guide`-like string if it exists — grep `swipe` in strings.xml — else add `m3e_ringing_hint`) for 2 s.
- **Accessibility**: also provide two plain `TextButton`s, "Snooze" and "Dismiss", reachable by TalkBack (they can be visually subtle,
  `labelLarge` under the track), and `customActions` semantics on the handle.
- Landscape: time left, slider right.

### `ui/ringing/SnoozePickerSheet.kt`
```kotlin
@Composable fun SnoozePickerSheet(currentMinutes: Int, onPick: (minutes: Int) -> Unit, onCancel: () -> Unit)
```
`ModalBottomSheet` titled "Snooze" with a grid of expressive `ToggleButton`/`Button(shapes = ButtonDefaults.shapes())` choices
(1, 5, 10, 15, 20, 30, 45, 60 minutes; the current one is pre-selected) plus a "Custom" `OutlinedTextField` (minutes, number keyboard)
and a confirm button. Dismissing the sheet → `onCancel`.

### `activities/AlarmActivity.kt` (rewrite UI only)
- Keep: `showOverLockscreen()`, alarm lookup (move `dbHelper.getAlarmWithId` into `lifecycleScope.launch(Dispatchers.IO)` and `finish()` if null),
  EventBus `AlarmEvent.Stopped` handling, `onNewIntent` (`ACTION_DISMISS_ALARM`, `ACTION_SNOOZE_ALARM` with duration), `snoozeAlarm()`,
  `dismissAlarmAndFinish()`, and `finishActivity()` without animation.
- Replace `setContentView(binding.root)` with `enableEdgeToEdge(); setContent { ClockTheme { RingingScreen(...) ; if (showSnoozePicker) SnoozePickerSheet(...) } }`.
  The time ticks every second (`produceState` with an aligned delay loop).
- In `snoozeAlarm()` when `!config.useSameSnooze`: `alarmController.silenceAlarm(id)`, then show `SnoozePickerSheet` (state flag) instead of
  `showPickSecondsDialog`; pick → `config.snoozeTime = minutes; dismissAlarmAndFinish(minutes)`; cancel → `dismissAlarmAndFinish()` (same as old).
- Remove the view-binding, the `onConfigurationChanged` override, and the swipe handler.

### `activities/SnoozeReminderActivity.kt`
Replace `showPickSecondsDialog` with `setContent { ClockTheme { SnoozePickerSheet(...) } }`, keeping identical logic (pick → save + snooze + finish;
cancel → `stopAlarm` + finish). The activity theme stays transparent, so only the sheet is visible.

### Cleanup
`res/layout/activity_alarm.xml` is no longer referenced. Do **not** delete files (the PM does deletions); just stop referencing it.
