# F17 — Expressive About screen

## Goal
Replace the Fossify commons About activity (launched by `MainActivity.launchAbout()`) with our own expressive About screen.
This fork must clearly credit upstream Fossify Clock and keep GPL-3.0 notices.

## Read first
- `app/src/main/kotlin/org/fossify/clock/activities/MainActivity.kt` (grep `launchAbout`; it lists FAQ items and licenses)
- `app/src/main/AndroidManifest.xml` (grep `<activity` to see how activities are declared)
- `app/src/main/kotlin/org/fossify/clock/activities/SettingsActivity.kt` (first 40 lines — the pattern for a Compose activity in this app)
- signatures: `ui/components/*.kt`, `ui/theme/Theme.kt`

## Create

### `ui/about/AboutScreen.kt` — `@Composable fun AboutScreen(versionName: String, onBack: () -> Unit, onOpenUrl: (String) -> Unit)`
- `LargeFlexibleTopAppBar` titled About (`org.fossify.commons.R.string.about`) with a back arrow.
- **Hero**: a 120.dp `ShapeBadge(MaterialShapes.Cookie12Sided, containerColor = primaryContainer)` with the app icon
  (`painterResource(R.mipmap.ic_launcher)` is not usable in Compose for adaptive icons — use `Icons.Rounded.Schedule` at 64.dp instead),
  rotating slowly; the app name (`R.string.app_name`, `displaySmallEmphasized`); "Version $versionName" (`labelLarge`) in a pill `Surface`.
- **FAQ** group (`segmentedGroup`): the same FAQ items as `launchAbout()` (title + text from the same string resources, including the
  google-play-only ones when `org.fossify.commons.R.bool.is_google_play_build`). Each item expands/collapses (`AnimatedVisibility`, chevron rotates).
- **Project** group: "Source code" → `https://github.com/ch7amada/clock-expressive`; "Based on Fossify Clock" →
  `https://github.com/FossifyOrg/Clock`; "Report an issue" → `https://github.com/ch7amada/clock-expressive/issues`. New `m3e_` strings.
- **Licenses** group: "Clock Expressive — GNU GPL v3.0" (→ `https://www.gnu.org/licenses/gpl-3.0.html`), "Fossify Commons — GPL v3.0",
  "Google Sans Flex font — SIL Open Font License 1.1" (→ `https://openfontlicense.org`), "Reorderable — Apache 2.0"
  (→ `https://github.com/Calvin-LL/Reorderable`), and "AndroidX / Jetpack Compose — Apache 2.0".
- Footer: "Made with Material 3 Expressive" in `labelMedium`, `onSurfaceVariant`.

### `ui/about/AboutActivity.kt`
`class AboutActivity : ComponentActivity()` → `enableEdgeToEdge(); setContent { ClockTheme { AboutScreen(BuildConfig.VERSION_NAME, ::finish) { url -> open with Intent.ACTION_VIEW, catching ActivityNotFoundException with a toast } } }`.
Register it in `AndroidManifest.xml` (`android:exported="false"`, same theme as SettingsActivity).

### MainActivity
`launchAbout()` → `startActivity(Intent(this, AboutActivity::class.java))`. Remove the now-unused FAQ and license code and imports.
