# F18 — Widget configuration screens in Compose

## Goal
`WidgetDigitalConfigureActivity` and `WidgetAnalogueConfigureActivity` use XML layouts, Fossify's `ColorPickerDialog`, and a SeekBar.
Rewrite their UI in Compose with an expressive layout: a live widget **preview** on top and controls below. The widgets themselves
(RemoteViews providers) stay unchanged.

## Read first
- `app/src/main/kotlin/org/fossify/clock/activities/WidgetDigitalConfigureActivity.kt` (163 lines — all)
- `app/src/main/kotlin/org/fossify/clock/activities/WidgetAnalogueConfigureActivity.kt` (129 lines — all)
- `app/src/main/res/layout/widget_digital.xml` (to mimic the preview), and grep `config_digital` / `config_analogue` string usage in the layouts
- signatures: `ui/components/*.kt`, `ui/theme/Theme.kt`; `docs/rewrite/api/Slider.md`

## Implement

### `ui/widget/ColorPickerSheet.kt`
`@Composable fun ColorPickerSheet(initial: Color, onPick: (Color) -> Unit, onDismiss: () -> Unit)` — a `ModalBottomSheet` with:
a row of the current Material theme colors (primary, secondary, tertiary, their containers, surface, inverseSurface, black, white) as
48.dp `MaterialShapes.Cookie6Sided` swatches (the selected one morphs to `Circle` with a check icon); a hue `Slider` + a saturation/value `Slider`
pair for custom colors (HSV via `android.graphics.Color.HSVToColor`); a hex `OutlinedTextField`; and Cancel/OK.

### `ui/widget/WidgetConfigScreen.kt`
`@Composable fun WidgetConfigScreen(title: String, preview: @Composable () -> Unit, bgColor: Color, textColor: Color, alpha: Float, onBgColor: (Color) -> Unit, onTextColor: (Color) -> Unit, onAlpha: (Float) -> Unit, onSave: () -> Unit, showTextColor: Boolean = true)`
- A preview card (`surfaceContainerHighest` with a subtle wallpaper-like gradient) showing `preview()` at its natural size.
- `SegmentedListItem` rows: Background color (swatch), Text color (swatch, if `showTextColor`), Transparency (an expressive `Slider` 0–100%).
- A large `Button(shapes = ButtonDefaults.shapes())` "Save" (`org.fossify.commons.R.string.ok` or save).

### Activities
Keep all logic (widget id handling, `IS_CUSTOMIZING_COLORS`, storing colors in config, `requestWidgetUpdate`, result intents) and only replace the
UI with `setContent { ClockTheme { WidgetConfigScreen(...) } }`. The digital preview is a Compose `Text` clock in the selected colors on a
rounded background (alpha applied); the analogue preview reuses `ui/clock/AnalogClock` scaled to 160.dp, tinted where possible.
